診断の「5項目」 切り口の候補 10 案

診断のグラフに出す5つの項目を、どの切り口にするかの候補です。質問は項目ごとに作るので、切り口が変わると質問も変わります。

  • グラフの形は見本です（架空の点数）
  • 各項目の下の小さい字は「その項目で何を聞くか」です
  • 2つの案を組み合わせることもできます（例：主な業務を先に聞いて、管理の会社には案5、仲介の会社には案6を出す）
案 1今の版

賃貸の業務ごと

  1. 物件・契約の管理台帳と期日を、どう管理しているか
  2. 書類・手続き契約・更新・退去の書類を、どう作っているか
  3. 入居者・オーナー対応お知らせ・返信・報告を、どう作り、どう記録しているか
  4. 集客・問い合わせ対応紹介文と、最初の返信を、どうしているか
  5. セキュリティとコンプライアンス個人情報を守るルール・環境と、お客様に出す前の確認の決まりがあるか
向いている相手
仲介も管理もやっている会社
強み
どの業務が弱いかが一目で分かる。登録後の「業務ごとの、できること・できないこと」とそのままつながる
弱み
仲介だけ・管理だけの会社は、やっていない業務の項目が低く出る
質問の例
更新・解約の予告・退去などの期日は、どうやって把握していますか？
案 2

契約の流れに沿って（時系列）

  1. 募集・広告空室の募集と、紹介文づくり
  2. 問い合わせ・内見最初の返信と、内見までの連絡
  3. 申込・契約申込みの受付と、契約書類づくり
  4. 入居中の管理入居者・オーナーとのやり取りと、修繕の受付
  5. 更新・退去期日の把握と、更新・退去の手続き
向いている相手
仲介から管理まで一貫してやっている会社
強み
仕事の順番どおりなので、答える人が迷わない。どの段階で止まっているかが見える
弱み
セキュリティやルールを聞く項目が無い。管理だけの会社は前半が低く出る
質問の例
退去の連絡を受けてから、立会いの案内を出すまでに、何を手でやっていますか？
案 3

AIの使い方の種類ごと

  1. 文章をつくる紹介文・お知らせ・メールの下書き
  2. 調べる・まとめる資料や長いやり取りを、要点にまとめる
  3. データを引き出す台帳に、言葉で聞いて答えをもらう
  4. 期日を知らせる更新・退去などの期日を、自動で知らせる
  5. 書類を自動でつくる契約者を選ぶだけで、書類とメールができる
向いている相手
「AIで何ができるか」を知りたい会社
強み
「今すぐできること → 仕組みを作ればできること」の順に並び、次に何ができるようになるかが伝わる
弱み
使い始めの会社は、後ろの3項目がほぼ 0 になり、グラフが小さくなる
質問の例
「来月が更新の契約は？」のような確認は、どうやっていますか？
案 4

困りごとごと

  1. 作業の速さ文章や書類づくりに、時間がかかりすぎていないか
  2. 抜け・漏れの防止期日や連絡の見落としが起きていないか
  3. 人による差の少なさ担当者によって、質や速さが変わらないか
  4. 情報の探しやすさ必要な情報が、すぐ見つかるか
  5. 返信の速さ問い合わせや連絡に、すぐ返せているか
向いている相手
AIに詳しくない経営者・店長
強み
AIの言葉を使わず、日ごろの悩みで答えられる。結果が「うちの課題」として伝わりやすい
弱み
AIをどこまで使えているかは直接は分からない。「AI活用レベル」という診断名と少しずれる
質問の例
この1年で、更新や退去の期日を見落としかけたことはありますか？
案 5管理にしぼる場合

賃貸管理の会社向け

  1. 物件・契約の台帳物件と契約の情報が、1か所にそろっているか
  2. 期日の管理更新・解約予告・退去を、見落とさない仕組みがあるか
  3. 書類づくり更新・退去の書類と案内を、どう作っているか
  4. 入居者対応連絡の受付・記録・返信を、どうしているか
  5. オーナー報告毎月の報告と提案を、どう作っているか
向いている相手
賃貸管理が中心の会社
強み
5項目すべてが管理の仕事。期日の知らせ・データの引き出し・退去書類の自動作成という話と、いちばん合う
弱み
仲介が中心の会社には当てはまらない（主な業務を先に聞いて、出し分ける必要がある）
質問の例
オーナーへの毎月の報告は、1件あたり何分くらいかけて作っていますか？
案 6仲介にしぼる場合

賃貸仲介の会社向け

  1. 物件の広告・紹介文紹介文と広告の文章を、どう作っているか
  2. 問い合わせへの返信最初の返信の速さと、型があるか
  3. 内見・提案希望の整理と、物件の提案をどうしているか
  4. 申込・契約書類申込みから契約までの書類を、どう作っているか
  5. その後の連絡返事待ちのお客様への連絡を、続けられているか
向いている相手
賃貸仲介が中心の会社
強み
5項目すべてが仲介の仕事。成約に近い話なので、効果が想像しやすい
弱み
管理が中心の会社には当てはまらない（主な業務を先に聞いて、出し分ける必要がある）
質問の例
ポータルサイトからの問い合わせに、最初の返信を返すまで、ふだんどのくらいかかりますか？
案 7

仕組み化の段階ごと

  1. データの整い方物件・契約の情報が、決まった形でそろっているか
  2. 型・ひな形のそろい方書類や返信の型を、全員が使っているか
  3. AIでの下書き文章づくりに、AIを使っているか
  4. 自動の知らせ期日や止まっている案件が、自動で届くか
  5. 自動の書類・メール選ぶだけで、書類とメールの下書きができるか
向いている相手
仕組みづくりまで提案したい場合
強み
「AIの前に、データと型が要る」ことが伝わる。どこから手をつけるかの順番がそのまま出る
弱み
どの業務の話かが見えにくい。答える人が、自社の仕事と結びつけにくい
質問の例
物件や契約の情報は、決まった形の表や管理ソフトに、全員が同じルールで入れていますか？
案 8

相手ごと（誰とのやり取りか）

  1. お部屋を探すお客様問い合わせ・内見・提案でのやり取り
  2. 入居者お知らせ・問い合わせ・更新・退去のやり取り
  3. オーナー報告・提案・相談のやり取り
  4. 業者・保証会社修繕の依頼や、保証・保険の手続き
  5. 社内引き継ぎ・記録・マニュアル・会議
向いている相手
連絡や文章づくりの負担が大きい会社
強み
「誰への連絡に時間を取られているか」で答えられるので分かりやすい
弱み
台帳や期日の管理など、やり取り以外の仕事が入らない
質問の例
修繕の依頼を業者に出すとき、依頼文はどうやって作っていますか？
案 9

得たい効果ごと

  1. 時間の短縮文章・書類・確認にかかる時間を、減らせているか
  2. ミスの防止期日の見落としや、書類の間違いを防げているか
  3. 成約・入居率返信の速さや提案が、成約や空室対策につながっているか
  4. お客様の満足入居者・オーナーへの対応が、速く・ていねいにできているか
  5. 人が育つ・引き継げる新人でも同じ質で仕事ができるか
向いている相手
経営者（数字や成果で判断する人）
強み
経営の言葉で結果が出るので、研修や仕組みづくりの必要性を説明しやすい
弱み
質問が「できていると思うか」になりやすく、答えが人の感じ方に左右される
質問の例
新しく入った人が、1人で問い合わせに返信できるようになるまで、どのくらいかかりますか？
案 10前の版

会社の準備ごと（前の版の言い直し）

  1. 使っている人社内で、どのくらいの人がAIを使っているか
  2. 情報の守り個人情報を入力しないルールと環境があるか
  3. 学ぶ機会研修・勉強会・教えられる人がいるか
  4. 仕事での効果時間が減った・質が上がったと言える業務があるか
  5. 会社の方針経営者が方針・予算・体制を示しているか
向いている相手
業種を問わず使いたい場合
強み
どの会社でも答えられる。研修（人が学ぶこと）の必要性と直接つながる
弱み
賃貸の仕事の話が出てこない。「この5項目がそもそも違うかも」と言われた切り口
質問の例
生成AIの使い方を学ぶ機会（研修・勉強会）はありましたか？

選ぶときの目安

  • 相手が管理会社にしぼれるなら：案5。期日の知らせ・データの引き出し・退去書類の自動作成という話と、いちばん合います
  • 仲介も管理も相手にするなら：案1（今の版）か、主な業務で案5と案6を出し分ける形
  • AIに詳しくない経営者に刺さる言い方を優先するなら：案4（困りごと）か 案9（得たい効果）
  • 仕組みづくりまで提案したいなら：案3（AIの使い方の種類）か 案7（仕組み化の段階）
