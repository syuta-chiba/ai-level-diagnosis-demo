賃貸の仕事のAI活用レベル診断 いまの中身

賃貸仲介・賃貸管理の会社に向けた、AI研修の集客に使う診断です。質問・選択肢・点数の付け方・結果と登録後に出す文面を、今の実物のまま載せています。

実物をさわる（見せる用の仮公開。登録しても何も保存されません）　／　答え終わった結果画面から見る

全体の流れ画面質問と選択肢点数とレベル結果と登録後に見せる中身取れる情報決めたことできていること・まだのこと

全体の流れ

LP → 診断 → 会社名とメールアドレスの登録、という流れです。相手は、賃貸物件を扱う会社（仲介・管理）にしぼっています。
  1. LP広告などから来た人が最初に見るページまだ無い
  2. 診断の入口「賃貸の仕事で、生成AIをどこまで使えているか」。無料・登録なしで結果が見られる・12問・約3分動く
  3. 質問 12問1画面に1問。選ぶと次へ進む。前の質問に戻れる動く
  4. 結果 ＋ 使い方を1つレベル（5段階）とグラフ。あわせて、そのレベルに合った使い方を1つだけ、短い箇条書きで見せる（登録なし）動く
  5. 「ここ、知りたくありませんか？」賃貸の仕事で、AIに今できること・できないこと。見出しだけ読めて、中身はモザイク動く
  6. 会社名とメールの登録登録するとその場でモザイクが外れる。開き直せる URL をメールで送る作成済み・未設置
  7. 提案資料を送る登録した会社を調べたうえで、その会社向けの提案資料（PDF など）をメールで送るこれから作る
  8. 研修の相談提案資料と、登録後の画面のいちばん下から、相談予約へ案内する予約先が未定

今は LP が無く、「診断の入口」の画面が LP の役目も兼ねています。LP を別に作る場合は、LP のボタンから診断の入口（または質問の1問目）へつなぎます。

10問点数を付ける質問（5つの面 × 2問）
2問点数を付けない質問（主な業務・従業員数）
5段階レベル（合計 30点満点）
10個登録なしで見せる使い方（レベル × 仲介／管理）
8業務・61項目登録後に見せる「できること・できないこと」

質問と選択肢

経営者・店長・推進担当の人が、自分から見た会社の様子で答えます。どの質問も、下の選択肢ほど進んでいる状態で、点数が高くなります（0〜3点）。

利用の広がり（2問・6点満点）

  1. 0点ほとんどいない／分からない
  2. 1点一部の詳しい人だけ
  3. 2点店舗や担当によっては半分くらい
  4. 3点多くの社員が日常的に使っている

  1. 0点まだ使われていない
  2. 1点調べ物や、ちょっとした文章の手直し
  3. 2点物件の紹介文・問い合わせへの返信・オーナーへの報告など、決まった作業の下書き
  4. 3点自社の物件情報や対応の記録と組み合わせた、業務の仕組みの一部

  1. 0点ない
  2. 1点口頭での注意くらい
  3. 2点文書のルールがある
  4. 3点ルールがあり、定期的に見直して周知している

Q4入居者・申込者・オーナーの個人情報を生成AIに入力しないための対策は、どこまでできていますか？

  1. 0点特に何もしていない
  2. 1点各自の判断に任せている
  3. 2点入力してよい情報の線引きを決めている
  4. 3点線引きに加え、法人向けプランなど情報が学習に使われない環境を用意している

点数とレベル

10問の合計（30点満点）でレベルが決まります。面ごとの点数（各6点満点）は、五角形のグラフで見せます。
レベル名前・点数結果画面に出る説明
Lv.1未着手
0〜6点		生成AIは、まだ会社として使われていない段階です。個人で試している人がいても、入居者やオーナーの情報の扱いが決まっていないため、使い始める前に最低限のルールを決めることが最初の一歩になります。
Lv.2個人任せ
7〜12点		使っている人はいるものの、使い方もルールも個人任せの段階です。詳しい人とそうでない人の差が広がりやすく、個人情報を入力してしまう心配も残ります。ルールと基本の使い方をそろえると、一気に使う人が増えます。
Lv.3試行
13〜18点		一部の業務で効果が見え始めている段階です。ここから先は、うまくいった使い方を社内で共有し、店舗や担当ごとの業務に合わせて広げられるかどうかが分かれ目になります。
Lv.4定着
19〜24点		生成AIが日々の業務に定着しつつある段階です。効果を測り、業務の手順そのものを生成AI前提に組み替えることで、さらに大きな時間短縮が見込めます。
Lv.5戦略的に活用
25〜30点		会社として計画的に生成AIを活用できている段階です。自社の物件情報や対応の記録との連携、問い合わせ窓口への活用など、競争力につながる使い方に取り組む余地があります。

結果と、登録後に見せる中身

AI がその場で文章を作っているわけではなく、用意した文面から、答えに合わせて選んで出しています。

① 登録なしで見せる：レベルに合った使い方を1つ

結果のすぐ下に、今のレベルと主な業務（仲介／管理）に合う使い方を1つだけ出します。「こうなる」2つ・やり方3手順・ポイント1つの、短い箇条書きです。

Lv.1（未着手）の会社に出す

仲介が中心・両方の会社物件の紹介文の下書きを、AIに作らせる

  • 紹介文づくりの時間が短くなる
  • 個人情報を入れずに始められる

やり方

  1. 物件の情報（間取り・設備・駅からの分数）を貼る
  2. 紹介文の案を3本出してもらう
  3. 物件の資料と照らし、直して載せる

ポイント：事実と合っているかは、必ず人が確かめる

管理が中心の会社入居者へのお知らせ文の下書きを、AIに作らせる

  • お知らせづくりの時間が短くなる
  • 個人情報を入れずに始められる

やり方

  1. 日時・内容・連絡先を箇条書きで渡す
  2. お知らせ文にしてもらう
  3. 日時と連絡先を確かめて配る

ポイント：書いていないことが足されていないか見る

Lv.2（個人任せ）の会社に出す

仲介が中心・両方の会社問い合わせへの最初の返信を、全員が同じ型で作る

  • 返信の速さと質が、担当者で変わらなくなる
  • 新人でも、すぐ同じ返信ができる

やり方

  1. 最初の返信メールの型を決める
  2. 同じ指示文を全員で使う
  3. 空き状況と家賃は、人が確かめて書き入れる

ポイント：値下げや入居日など、決まっていない約束はさせない

管理が中心の会社更新や退去の案内メールを、全員が同じ型で作る

  • 毎月の連絡の質が、担当者で変わらなくなる
  • 書く時間が短くなる

やり方

  1. 更新・解約・退去立会いの案内の型を決める
  2. 同じ指示文を全員で使う
  3. 名前・日付・金額は、後から人が書き入れる

ポイント：名前や部屋番号は、AIに入力しない

Lv.3（試行）の会社に出す

仲介が中心・両方の会社紹介文づくりを物件登録の流れに入れて、かかる時間を測る

  • 物件登録にかかる時間が、数字で分かる
  • 「使える人だけ」から、全員の手順になる

やり方

  1. 「AIで下書き → 担当が確認 → 掲載」と手順を決める
  2. 1件にかかる時間を、前後2週間ずつ記録する
  3. 結果を比べて、社内に共有する

ポイント：掲載前の事実確認は、手順から外さない

管理が中心の会社期日が近い契約を毎週一覧にして、案内の下書きまでを手順にする

  • 期日の見落としが減る
  • 案内にかかる時間が、数字で分かる

やり方

  1. 更新・解約の予告・退去立会いが近い契約を、毎週台帳から抜き出す
  2. 一覧をもとに、案内文の下書きをAIで作る
  3. 担当者が確かめて送る

ポイント：見落としの件数と時間を、始める前と後で比べる

Lv.4（定着）の会社に出す

仲介が中心・両方の会社社内のマニュアルや過去の対応記録に、AIが答える仕組みを試す

  • 資料を探す時間が減る
  • ベテランに聞かなくても、答えが分かる

やり方

  1. マニュアル・よくある質問・対応記録を集める（個人が分からない形で）
  2. 情報が外に出ない法人向けの環境に読み込ませる
  3. 「初期費用の説明のしかたは？」と聞いて試す

ポイント：どの資料に書いてあるかを、必ず付けて答えさせる

管理が中心の会社物件と契約のデータに、言葉で質問できるようにする

  • 台帳を開いて探す手間がなくなる
  • 期日の近い契約が、毎朝届く

やり方

  1. 台帳を、情報が外に出ない法人向けの環境とつなぐ
  2. 「来月が更新の契約は？」と言葉で聞いて試す
  3. 期日の近い契約を、毎朝知らせるようにする

ポイント：大事な期日は、契約書でも確かめる

Lv.5（戦略的に活用）の会社に出す

仲介が中心・両方の会社営業時間外の問い合わせに、AIが一次対応する窓口をつくる

  • 夜間・定休日の問い合わせを取りこぼさない
  • 翌朝、希望日がそろった状態で引き継げる

やり方

  1. 答えてよい範囲を決める（空き状況・家賃は約束しない）
  2. AIが、お礼と内見の希望日の聞き取りまで行う
  3. 翌営業日に、担当者へ引き継ぐ

ポイント：すぐ人に引き継ぐ条件を、先に決めておく

管理が中心の会社契約者を選ぶだけで、退去の書類と案内メールができる仕組みをつくる

  • 退去の書類づくりが、選ぶだけで終わる
  • 知らせ → 書類 → 連絡が、ひと続きになる

やり方

  1. 契約者を選ぶ
  2. 解約受付の書類・退去立会いの案内・メールの下書きが自動でできる
  3. 人が読んで、金額を入れて送る

ポイント：費用の負担と金額は、人が決める

② 登録の誘い

賃貸の仕事で、AIに今できること・できないこと。ここ、知りたくありませんか？

上の使い方は、ほんの一例です。たとえば、こんなこともできます。

  • 期日が近い契約を、知らせてくれる
  • データを、言葉で聞くだけで引き出せる
  • 契約者を選ぶだけで、退去の書類とメールの下書きができる

登録すると読めるもの

  • 業務ごとの、AIの使いどころ
    • 今すぐ任せられること
    • 仕組みを作ればできること
    • まだ任せられないこと
  • あなたの会社の、次の一手

会社名とメールアドレスを登録すると、下のモザイクが外れます。　／　ボタンの文言：「登録して、次の一手を知る」

③ 登録後に見せる：賃貸の仕事で、AIに今できること・できないこと

業務ごとに4つに分けて見せます。「仕組みを作ればできる」は、物件や契約のデータとAIをつなぐ前提のもの（期日の知らせ、データへの質問、書類やメールの自動作成）です。主な業務が仲介なら仲介の業務を先に、管理なら管理の業務を先に並べます。中身は一般に知られていることをもとに作った下書きです。賃貸の実務に詳しい人の確認はまだ受けていません。

業務今すぐ任せられる仕組みを作ればできる人の確認が要るまだ任せられない
物件・契約の管理
管理
  • 管理の手順書や、チェックリストの下書き
  • 台帳の入力の抜けや、書き方のばらつきを見つける（個人情報を除いた表で）
  • 更新・解約の予告・退去立会い・保険や保証の更新など、期日が近い契約を毎朝一覧にして知らせる
  • 「来月が更新の契約は？」「3か月以上空いている部屋は？」と言葉で聞くと、台帳から答えが返ってくる
  • 家賃の入金の遅れや、対応が止まっている案件を拾って知らせる
  • 台帳から拾った結果（元のデータが古い・抜けていると、そのまま間違って出る。大事な期日は契約書で確かめる）
  • 台帳に入っていないことを知っていること
  • 期日を過ぎたときに、どう対応するかの判断
更新・退去の手続きと書類
管理
  • 更新の案内、解約の受付、退去立会いの日程調整など、メールや手紙の文面づくり
  • 手続きの流れを、入居者向けにやさしく説明する文
  • 契約者を選ぶだけで、物件と契約の情報から、解約受付の書類・退去立会いの案内・更新の案内を自動で作る
  • 書類と一緒に、送るメールの下書きまで自動で用意する
  • 期日の知らせから、そのまま書類づくりに進めるようにつなぐ
  • 自動で入った名前・日付・金額（送る前に必ず人が見る）
  • 敷金の精算書の下書き（金額は人が決めて入れる）
  • 原状回復の費用を、誰がいくら負担するかの判断
  • 更新の条件や、家賃の変更を決めること
入居中の対応
管理
  • 点検・工事・清掃などのお知らせ文
  • 問い合わせや苦情への返信の下書き
  • よくある質問と回答の一覧づくり
  • 入居者からの連絡を受け付けて、急ぎかどうか・誰が対応するかの案を付けて担当者に渡す
  • 修繕の受付内容から、業者への依頼文を自動で下書きする
  • 仕分けの結果（急ぎの連絡を見落としていないか）
  • 費用を誰が負担するかの判断
  • 騒音など、入居者どうしのトラブルの仲裁
  • 水漏れや鍵など、急ぎの場面での判断と手配
オーナーへの対応
管理
  • 提案書の下書き
  • 空室対策の案を幅広く出す
  • 入居状況・入金・対応の記録から、毎月の報告書の下書きを自動で作る
  • 家賃の見直しを提案する資料（自社の成約の記録を渡して整理させる。数字は人が確認する）
  • 今の家賃の相場を知っていること（渡したデータ以外の数字は当てにできない）
  • 投資や税金についての助言が正しいことの保証
物件の広告・紹介文
仲介
  • 物件情報から、紹介文やキャッチコピーの案を何本も作る
  • 同じ物件を、学生向け・ファミリー向けなど、読む人に合わせて書き分ける
  • 物件を登録すると、紹介文・SNSの投稿・チラシの文案がまとめて出てくる
  • 部屋の写真から特徴を文章にしたもの（写っていないことを書くことがある）
  • 周辺の店や施設の紹介（古い情報や、実在しない店を書くことがある）
  • 書いた内容が事実かどうかを確かめること（駅からの分数、設備、広さは、AIには確かめられない）
  • 広告の決まりに合っているかの最終判断（根拠なしに使えない言葉や、載せなければいけない項目）
問い合わせ・内見の対応
仲介
  • 最初の返信、内見の日程調整、内見後のお礼メールの下書き
  • 外国語の問い合わせを訳して、返信の下書きを作る
  • お客様の希望を整理して、提案の切り口を出す
  • 自社の物件リストから、希望の条件に合う候補を出す
  • 営業時間外の問い合わせに、お礼と希望日の聞き取りまで自動で返す
  • 候補の物件や比較表（条件の読み違い、数字の写し間違いがないか）
  • 部屋の実際の様子（音、におい、日当たり）を知ること
  • 値下げや入居条件の交渉の判断
入居の契約・書類
共通
  • 契約の流れや、用意してもらう書類の案内文
  • むずかしい条文を、やさしい言葉で説明する文の下書き
  • 書類の記入漏れを防ぐチェックリストづくり
  • 申込みの内容から、契約書類のひな形に名前や条件を自動で入れる
  • 契約書や重要事項説明書の下書き・読み合わせの手伝い（宅地建物取引士が全文を確認する）
